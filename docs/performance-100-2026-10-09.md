# Weryfikacja 100 równoczesnych uczestników — 2026-10-09

Test wykonano na osobnych kopiach produkcyjnych aplikacji. Właściwe wyniki,
materiały i konfiguracja badania nie były używane przez test.

## Środowisko i zakres

- Apple M4, 10 rdzeni, 16 GiB RAM, macOS arm64.
- Node.js 26.10.0, Next.js 15.5.27, better-sqlite3 12.10.1, SQLite 3.53.2.
- Jedna instancja aplikacji; drugi przebieg dodatkowo przez Nginx 1.30.5.
- 100 równoległych sesji HTTP dla filmów, następnie 100 dla zdjęć.
- Po 2 stymuli na uczestnika w obu częściach, pytanie tak/nie w obu częściach,
  test ekranu, przydział skal 50/50 i ponowienia zapisu.
- Jednoczesne pobranie przez 100 klientów pliku testowego po 32 MiB.
  Każdy transfer sprawdzono pod względem rozmiaru i SHA-256.
- Brak czasu namysłu między seriami żądań. Klient i serwer korzystają z tej samej
  maszyny i loopback HTTP. To test API i dostarczania plików, bez odtwarzania
  sztucznego filmu, łącza internetowego i wielogodzinnego przebiegu.

Próg testu: brak błędów, poprawne liczby rekordów i p95 API do 500 ms. Oba
przebiegi przeszły. W drugim przebiegu eksport CSV działał już w partiach.
Surowe dane: [bez proxy](performance-100-2026-10-09.json),
[przez Nginx](performance-100-nginx-2026-10-09.json).

Łączne pobranie 3200 MiB przez 100 klientów trwało lokalnie około 2,05 s bez proxy
i 1,86 s przez Nginx. To pomiar loopback; nie opisuje prędkości pobierania przez
uczestników w Internecie. Test Nginx dodatkowo potwierdził poprawność `HEAD`, MIME,
cache, zakresów `206`/`416`, odrzucania nieznanego `Host` oraz dowiązań symbolicznych.
Szablon przeszedł także `nginx -t`.

## Pozostałe sprawdzenia

- 51 testów automatycznych: dotychczasowy przebieg, import materiałów, pytania,
  passkeys, hasła, migracje oraz nowe testy cache, indeksów, WAL i duplikatów.
- Duży eksport 1100 ocen z wolnym odbiorcą: wszystkie rekordy zachowane,
  możliwy zapis w trakcie eksportu, nowe rekordy wyłączone z rozpoczętego pliku.
- Kopia zapasowa z otwartej bazy zawierającej dane w WAL: kompletna, integralna,
  uprawnienia `600`, brak możliwości nadpisania istniejącej kopii.
- Start produkcyjny bez poprawnych danych administratora zatrzymuje się przed
  uruchomieniem serwera.
- Produkcyjny build i lint zakończyły się powodzeniem.
